PRAKRITI AI
"आपकी साथी, आपकी सहायक, आपकी शक्ति।"

A Hindi-first personal AI assistant with Indian cultural design, featuring voice interaction, knowledge base, and utility tools.

Features
🎙️ Voice-first interaction (speak → listen → respond)
📚 Gyan (Knowledge) - Indian history, science, technology, health
🔧 Tools - Calculator, Math Solver, Translator, Writer, Notes
🟢 Online/Offline mode toggle
👤 Mature Indian AI avatar with multiple states
🇮🇳 Indian architectural motifs and design language
💾 Local-first data storage (IndexedDB + localStorage)
📱 PWA installable
